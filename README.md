<div align="center">
  <h2>Hammers Recipes</h2>
</div>

<div align="center">
  <h3>Wooden Hammer</h3>
  <p>You can use any type of planks to craft the Wooden Hammer.</p>

  ![wooden hammer recipe](https://cdn.modrinth.com/data/cached_images/71a9c17812e39273a4810038f8d00b7ef165166b.png)

  <p>Even using various types at the same time.</p>
  
  ![wooden hammer recipe mixed](https://cdn.modrinth.com/data/cached_images/37758a690a00fa44475fd5e08d7de3ab856181c2.png)

  <h3>Stone Hammer</h3>
  <p>Like the Wooden Hammer, you can use any vanilla stone crafting for this.</p>

  ![stone hammer recipe](https://cdn.modrinth.com/data/cached_images/6d8c9b04552044824e6d68b582947012291de9f0.png)

  <h3>Golden Hammer</h3>

  ![golden hammer recipe](https://cdn.modrinth.com/data/cached_images/b8168cc1d8823c650668e2376545848ceac7e192.png)

  <h3>Diamond Hammer</h3>

  ![diamond hammer recipe](https://cdn.modrinth.com/data/cached_images/7e877f98b9a787c7b476e6bd06ebd877a4cc1682.png)

  <h3>Netherite Hammer</h3>
  <p>Using the <strong>smithing table</strong>, a <strong>netherite upgrade</strong>, the <strong>diamond hammer</strong> and one <strong>netherite ingot</strong> you will get the netherite upgrade for the Diamond Hammer.</p>

  ![netherite hammer recipe](https://cdn.modrinth.com/data/cached_images/347f3d9f46805c4185100904b4bcf3902e96a081.png)
</div>


<div align="center">
  <h2>Enchanting the Hammers</h2>
</div>

<div align="center">
  <p>You can enchant the hammers with all the vanilla enchantments available for the pickaxe.</p>
  
  ![enchanting hammers](https://cdn.modrinth.com/data/cached_images/97a7dbb21f7d65647601ea95dba389e318521604.png)

  <p>Then you can enchant them at the enchanting table as well.</p>
    
  ![enchanting table](https://cdn.modrinth.com/data/cached_images/795cf07ccbb96a5f13d9f2ef1c2a880a8aceb889.png)

  <p>Also, you can repair and enchant them at the anvil like you do with the vanilla tools.</p>

  ![hammers at anvil](https://cdn.modrinth.com/data/cached_images/1e47347999ea8cd80f189220cb78501eafe275dc.png)
</div>
